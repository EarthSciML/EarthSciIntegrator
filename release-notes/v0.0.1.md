## EarthSciIntegrator v0.0.1

First registered release: an early preview. EarthSciIntegrator is a time
integrator for EarthSciML `.esm` models, written to one specification
([`spec/`](https://github.com/EarthSciML/EarthSciIntegrator/tree/v0.0.1/spec))
and implemented natively in Julia (`EarthSciIntegrator`) and in Rust
(`earthsci-integrator`, `-planner`, `-solvers`, `-mpi`). A shared conformance
suite checks the two implementations against each other in CI.

Everything is tested on the toy problems in `spec/toy-problems.md`; work to
scale to full-size models is under way. The public API and the run
configuration format may change in any 0.0.x or 0.x release.

### What is in this release

- **Run configuration** (`esm_integrator` 0.1.0): a JSON document, checked
  against a JSON Schema, that names the operators, the method and step size
  or tolerance for each, how they are split and subcycled, and what to
  differentiate. Invalid configurations are refused with a `ConfigError`.
- **Methods** from tableaus shipped as data: explicit Runge–Kutta and SSP
  (Forward Euler, Heun, RK4, BS3, Tsit5, SSPRK33/43/104, WRF RK3), Rosenbrock
  (Rosenbrock23, ROS2, ROS3P, Rodas3/4/5P and the KPP Ros/Rodas family), and
  SDIRK/ESDIRK (Backward Euler, Theta, SDIRK2, TRBDF2, Kvaerno3/4), with
  IMEX Euler, plus adaptive step-size control.
- **Operator splitting as a schedule tree** (`leaf`, `sequence`, `strang`,
  `subcycle`, `map`, ...), run by a schedule interpreter.
- **Tape, replay and discrete adjoints:** a forward run records a tape,
  `replay` reproduces it bit for bit, and `gradient` returns the discrete
  adjoint with respect to the initial state and parameters, including through
  implicit solves.
- **Planner:** reads a run configuration with an `.esm` model (through
  EarthSciAST and EarthSciASTDiff), infers each operator's locality and
  Jacobian band structure, and writes an inspectable, hashed plan. Planned
  operators run in both runtimes, forward and adjoint.
- **Julia:** `build_run`, `forward!`, `replay`, `gradient`, `odefunction`,
  `plan` / `build_plan_run`, and a SciMLBase extension.
- **Rust:** the same operations in `earthsci-integrator` (core, schedule,
  tape and adjoint), `earthsci-integrator-planner` and
  `earthsci-integrator-solvers`. `earthsci-integrator-mpi` is a placeholder
  crate reserving the name for the MPI executor; it has no functionality yet.

Documentation: <https://earthsci.dev/integrator/>.

This is a new package, so nothing here breaks an earlier release. The
